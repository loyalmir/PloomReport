월간 일정 가져오기 — 엑셀

매달 받는 엑셀 파일(.xlsx)을 그대로 선택하세요. 전 팀·날짜·매장·주소를 알아서 읽어 채웁니다.

새로 시작: 기존 일정을 비우고 이 파일로 채움 (다음 달 새 파일 받을 때). 기존에 더하기: 지금 일정에 이어붙임 (A팀·B팀 같이 볼 때). 어느 쪽이든 매장별 재고·설명 기록은 계속 남습니다.

또는 CSV 붙여넣기

노션 체크리스트를 복사해 붙여 넣어도 됩니다.

전체 일정

탭하면 보고 화면이 열립니다. 길게 눌러 삭제.

방문자 이름

사전방문 보고에 "방문자 :" 로 들어가는 이름입니다. 대타로 쓰는 사람은 여기서 자기 이름으로 바꿔서 쓰면 돼요.

재고 입력 방식

본인 운영 방식에 맞게 골라두세요. 마감재고 화면의 입력칸이 바뀝니다.

한 팀만 운영하면 창고 + 운영, 여러 팀을 관리하면 총재고 − 판매가 편해요.

보고 모드 표시

안 쓰는 보고는 꺼두세요. 편집창 상단 탭에서 숨겨집니다. (사전방문은 항상 표시)

사진 분석 (Anthropic API)

사진을 올리면 주변 환경 설명 초안을 자동으로 만들어 줍니다. 키는 이 폰에만 저장되고 어디에도 전송·업로드되지 않습니다.

키 발급: console.anthropic.com → API Keys → Create Key. 처음에 5~10달러만 충전하면 한참 씁니다.

Firebase 설정 (기기 동기화용)

Firebase 콘솔 → 프로젝트 설정 → 내 앱 → firebaseConfig 코드를 아래에 붙여넣으세요. 이 기기에만 저장되고 GitHub에는 올라가지 않습니다.

기기 동기화 — 링크 코드

폰과 아이패드에 같은 코드를 입력하면 일정·재고·기록이 실시간으로 연결됩니다. 코드는 영문+숫자 조합으로 원하는 걸 쓰면 돼요. (사진은 용량이 커서 각 기기에 따로 저장됩니다.)

같은 코드를 쓰는 사람은 같은 데이터를 봐요. 코드는 비밀번호처럼 아무도 모르는 걸로 쓰세요. 코드를 지우고 연결하면 로컬 저장으로 돌아옵니다.

앱 새로고침

홈화면 앱이 오래된 버전을 보여줄 때 눌러주세요. 데이터는 그대로 유지됩니다.
